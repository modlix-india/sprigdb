# Known differences between MongoDB 8.0.34 and SprigDB in Mongoose 8.24.8's
# own suite (deploy/compose/clients-mongo/run.sh mongoose, CI's
# heavy-protocols workflow). Test ids are mocha xunit's "<suite title>.<test
# title>"; globs match them. Format:
#   <target-glob> <fail|skip|flaky|exclude> <test-glob> :: <reason>
# (deploy/compose/ci/outcomes.py; the target is always "sprig"). A test that
# fails on MongoDB too is never counted against SprigDB.
#
# From the whole suite run on a laptop on 15 and 16 Nov 2026 (test/*.test.js
# and test/docs/*.test.js, 4,220 tests, with START_REPLICA_SET=1, as CI also
# sets it): every test that passes on MongoDB 8.0.34 and fails through
# SprigDB is listed here.

# Legacy `2d` indexes are not built (a non-goal of the geo work); `$near`,
# `$nearSphere` and `$within` on legacy pairs need one.
sprig fail *query casting $near*with * :: legacy 2d indexes are not built
sprig fail *query casting $within* :: legacy 2d indexes are not built
sprig fail *querying: 2d*$maxDistance with arrays :: legacy 2d indexes are not built
sprig fail *querying: 2d*$near (gh-309) :: legacy 2d indexes are not built
sprig fail *querying: 2d*$nearSphere with arrays* :: legacy 2d indexes are not built
sprig fail *querying: 2d*$within arrays* :: legacy 2d indexes are not built
sprig fail *2d indexed field without value is saved* :: legacy 2d indexes are not built

# Time-series and clustered collections are refused (designs only).
sprig fail *createCollection()*enforces expire* :: time-series collections are refused
sprig fail *mongodb actually removes expired documents* :: time-series collections are refused
sprig fail *createCollection()*respects timeseries* :: time-series collections are refused
sprig fail *avoids trying to drop timeseries collections* :: time-series collections are refused
sprig fail *createCollection()*respects clusteredIndex* :: clustered collections are refused

# Not built yet.
sprig fail *Mongo 3.6 options*adds hint option* :: aggregate's hint doesn't order the documents by the index

# The test reads the host from a URI without credentials; SprigDB needs a login.
sprig fail *openUri*with mongoose.createConnection()* :: the test's URI pattern doesn't allow user:password@
